# Lumiere Kebaya Landing Page

Landing page resmi untuk **Lumiere Kebaya**, brand penyewaan kebaya premium dengan fokus pada tampilan elegan, modern, dan user-friendly.

Project ini dibangun untuk menampilkan profil brand, katalog kebaya unggulan, alur pemesanan/sewa, testimoni pelanggan, dan informasi kontak dalam satu pengalaman halaman yang rapi.

## Tentang Project

Lumiere Kebaya hadir sebagai showcase digital untuk membantu calon pelanggan:

- Mengenal brand dan value Lumiere Kebaya
- Menjelajahi koleksi kebaya unggulan
- Memahami proses sewa yang mudah
- Melihat ulasan/testimoni pelanggan
- Menghubungi brand dengan cepat

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN/Radix UI components

## Struktur Halaman Utama

Landing page ini disusun dari beberapa section inti:

- `Navigation` - navigasi utama
- `Hero` - headline dan ajakan utama
- `FeaturedCatalog` - katalog kebaya pilihan
- `HowToRent` - langkah-langkah sewa
- `About` - profil singkat Lumiere Kebaya
- `Testimonials` - ulasan pelanggan
- `Footer` - informasi penutup dan kontak

## Menjalankan Project Secara Lokal

1. Install dependencies:

```bash
npm install
```

2. Jalankan development server:

```bash
npm run dev
```

3. Build untuk production:

```bash
npm run build
```
